# funbattle

个人参加数据竞赛（如 DataFountain）时的代码归档仓库，按赛事 ID 分目录存放。

## 安装

```bash
pip install funbattle
```

## 示例

```python
import funbattle.battles.datafountain.bt557
```

各赛事目录下的代码是针对具体比赛数据集编写的一次性脚本，不构成通用 API，
使用前请先阅读对应目录下的说明。
